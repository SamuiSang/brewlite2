# MA TRẬN TRUY VẾT YÊU CẦU DỰ ÁN BREWLITE (TRACEABILITY MATRIX)

- **Dự án:** BrewLite – Hệ thống Đặt đồ uống Trực tuyến (Mobile-first / PWA)
- **Tài liệu:** `docs/traceability-matrix.md`
- **Mục tiêu:** Đảm bảo tính nhất quán và khả năng truy vết 100% hai chiều từ Yêu cầu nghiệp vụ (FR/NFR) -> Sơ đồ thiết kế UML -> Mã nguồn thực tế -> Ca kiểm thử tự động (Unit / Integration / E2E).
- **Chủ trì tổng hợp:** **Hàn Minh Hiếu (Product Owner / Fullstack Dev)**
- **Phiên bản cập nhật:** 2.0 (Tích hợp định mức nguyên vật liệu pha chế RecipeItem/Ingredient và quy trình thanh toán QR Sandbox Webhook 2 bước theo bài giảng 28/10 của Thầy Phiêu).

## 2. Ma trận Truy vết Yêu cầu Phi chức năng (NFR Traceability)

| Mã NFR | Nhóm chất lượng | Tiêu chí kỹ thuật bắt buộc | Thành phần kiến trúc & Triển khai thực tế | Phương pháp kiểm chứng |
| :---: | :--- | :--- | :--- | :--- |
| **NFR-01** | **Hiệu năng (Performance)** | API Latency < 300ms; FCP < 1.5s trên Mobile. | • Next.js App Router (SSR & Client Caching)<br>• Prisma Query tối ưu hóa chỉ mục (Indexes) | Benchmark bằng Postman Collection & Lighthouse audit. |
| **NFR-02** | **Bảo mật (Security)** | Mật khẩu Bcrypt salt >= 10; JWT Authentication; CORS Whitelist; DB không public; Hardware Firewall. | • `ADR-005: Security JWT & Health Check`<br>• `apps/api/src/auth/jwt-auth.guard.ts`<br>• Hardware Firewall lọc IP/Port Whitelist | Unit Test kiểm tra thuật toán hash; Kiểm tra scan bảo mật không mở port 5432 ra Internet. |
| **NFR-03** | **Tính sẵn sàng & Giám sát** | Endpoint Health Check `/health`; Tự phục hồi container khi crash; VPN cho nhân viên từ xa. | • `apps/api/src/health/health.controller.ts`<br>• Docker Healthcheck directive trong Compose/Cloud | Smoke Test trong CD Pipeline (`GET /api/v1/health` trả về 200 OK qua `SELECT 1`). |
| **NFR-04** | **Tính nhất quán dữ liệu** | ACID Database Transaction; Không bao giờ âm kho nguyên liệu (`Ingredient.stockQuantity >= 0`); Không trừ tiền 2 lần. | • `prisma.$transaction`<br>• Optimistic Locking (cột `version`)<br>• Idempotency-Key trong bảng `Payment` | Kịch bản kiểm thử đồng thời (Concurrency Test 2 khách tranh mua ly cuối cùng trong 1 tích tắc). |
| **NFR-05** | **Khả năng triển khai (DevOps)** | Chạy một lệnh `docker-compose up`; Tự động hóa CI/CD; Báo cáo LaTeX Overleaf. | • Monorepo `apps/web`, `apps/api`, `docs/`<br>• `.github/workflows/ci.yml` & `cd.yml`<br>• File báo cáo `report.tex` chuẩn Thầy Phiêu | Minh chứng Pull Request kích hoạt GitHub Actions chạy Pass (Xanh) và Chặn merge khi Fail (Đỏ). |
